# SQL Marketplace E-Commerce Analysis

## Project Overview
This project analyzes an e-commerce marketplace database using SQL. The objective is to extract business insights, improve data quality, and simulate real-world Data Analyst tasks commonly found in ERP and business environments.

## Key Topics
- Data Quality Checks
- Duplicate Detection
- Missing Value Analysis
- Customer Analysis
- Seller Performance Analysis
- Product Category Analysis
- Supply Chain KPIs
- Order Status Monitoring
- ERP Data Mapping
- Business Process Understanding

## SQL Techniques
- SELECT
- JOIN
- GROUP BY
- HAVING
- CASE WHEN
- Subqueries
- Common Table Expressions (CTE)
- Window Functions (ROW_NUMBER, RANK)
- Aggregations

## Tools
- SQL
- SQLite
- Google Colab
- Python (Pandas)

## Business Value
The project demonstrates how SQL can be used to:
- Improve data quality
- Detect inconsistencies
- Analyze business processes
- Support decision-making
- Understand ERP-style data relationships
